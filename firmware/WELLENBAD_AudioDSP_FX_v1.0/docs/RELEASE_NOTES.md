# RTAL AudioDSP FX Module v1.0.0 — FX0047 FINAL

## Basis

This release is based directly on:

```text
RTAL Audio DSP Platform
0.1.0ai Build0046l StableSyncDelay
```

## Functional changes from Build0046l

**None.**

The v1.0.0 / FX0047 promotion changes only release identity, package naming and release documentation. The following remain unchanged from Build0046l:

- effect algorithms
- effect routing
- I2S audio format
- sample rate and block size
- DMA geometry
- DSP parameters
- interpolation methods
- delay synchronization algorithm
- FX-Link protocol
- GPIO routing
- preset formats
- real-time behavior

## Release purpose

FX0047 establishes Build0046l as the first public stable 1.0 release and defines the supported release pair:

```text
RTAL WELLENBAD v1.5.0 B0072 A015 FINAL
+
RTAL AudioDSP FX Module v1.0.0 FX0047 FINAL
```
